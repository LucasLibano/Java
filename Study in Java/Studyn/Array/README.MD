- Exercícios de Vetores em Java

Este repositório contém uma coleção de exercícios resolvidos em Java, com foco em vetores (arrays) e lógica de programação. Os exercícios seguem a proposta do curso do professor Nelio Alves.

- Objetivo

Praticar conceitos fundamentais de programação, como:

Estruturas de repetição (for)

Vetores (arrays)

Condicionais (if/else)

Entrada de dados com Scanner

Cálculos (soma, média, porcentagem)

Manipulação de múltiplos vetores

- Lista de Exercícios
🔹 1. Soma de Vetores (soma_vetores)

Lê dois vetores A e B e gera um terceiro vetor C com a soma dos elementos correspondentes.

🔹 2. Abaixo da Média (abaixo_da_media)

Calcula a média de um vetor de números reais e exibe os valores abaixo da média.

🔹 3. Média dos Pares (media_pares)

Calcula a média apenas dos números pares de um vetor. Caso não existam, exibe uma mensagem.

🔹 4. Pessoa Mais Velha (mais_velho)

Lê nomes e idades e exibe o nome da pessoa mais velha.

🔹 5. Aprovados (aprovados)

Lê nomes e notas de alunos e exibe aqueles com média maior ou igual a 6.0.

🔹 6. Dados de Pessoas (dados_pessoas)

Analisa altura e gênero de um grupo e exibe:

Maior e menor altura

Média de altura das mulheres

Quantidade de homens

🛠️ Tecnologias Utilizadas

Java 17+
