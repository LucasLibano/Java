🎯 Estruturas Repetitivas (while)
Neste repositório estou registrando meus exercícios sobre estruturas repetitivas do tipo **while** em Java.  

🖥️ O que pratiquei
Durante esta lista de exercícios pratiquei:

💻 Entrada e validação de dados  
⚙️ Processamento com repetição controlada por condição  
🔁 Estrutura de repetição `while`  
🧠 Lógica de persistência de dados até que uma condição seja satisfeita  
🔹 Uso de condicionais dentro de laços  
🔹 Leitura de coordenadas e tomada de decisão  
🔹 Contagem e classificação de ocorrências em um loop  
🔹 Controle de fluxo com encerramento condicional (`break`)  

📚 Exercícios Resolvidos

**Exercício 01 — Senha Válida**  
Descrição: Escrevi um programa que repete a leitura de uma senha até que ela seja válida.  
Para cada senha incorreta, é exibida a mensagem **"Senha Invalida"**.  
Quando a senha correta (2002) é informada, aparece **"Acesso Permitido"** e o programa encerra.  

---

**Exercício 02 — Quadrante**  
Descrição: O programa lê as coordenadas **(X, Y)** de vários pontos e indica o quadrante ao qual pertencem.  
O algoritmo é encerrado quando pelo menos uma das coordenadas for **nula (0)**, sem imprimir nenhuma mensagem.  

---

**Exercício 03 — Posto de Combustível**  
Descrição: Desenvolvi um programa que contabiliza o número de clientes por tipo de combustível abastecido.  
Os códigos são:  
1️⃣ Álcool  
2️⃣ Gasolina  
3️⃣ Diesel  
4️⃣ Fim  

O programa encerra ao receber o código **4**, exibindo **"MUITO OBRIGADO"** e o total de abastecimentos por tipo.
