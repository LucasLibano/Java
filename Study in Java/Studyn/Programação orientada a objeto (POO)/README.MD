🎯 Programação Orientada a Objetos em Java

Este repositório reúne uma série de exercícios práticos de Programação Orientada a Objetos (POO) em Java, desenvolvidos com o propósito de consolidar conceitos fundamentais da linguagem, como criação de classes, métodos, atributos, encapsulamento e manipulação de dados de entrada e saída.

🖥️ Competências Desenvolvidas

Durante o desenvolvimento desta lista de exercícios, foram praticados os seguintes tópicos:

- Definição e instanciação de classes e objetos.
- Criação e uso de métodos com e sem retorno.
- Aplicação de operações matemáticas em atributos.
- Uso de estruturas condicionais para tomada de decisão.
- Organização de código em pacotes.
- Sobrescrita do método toString() para exibição de dados formatados.
- Leitura e processamento de dados via classe Scanner.

📚 Exercícios Desenvolvidos

🟩 Exercício 01 — Cálculo e Comparação de Áreas de Triângulos

Descrição:
Programa que lê as medidas de dois triângulos (X e Y) e calcula suas áreas utilizando a fórmula de Heron.
Após o cálculo, compara as áreas e exibe qual triângulo possui a maior.

Conceitos abordados:

Classe Triangulo com atributos a, b, c.

Método area() para o cálculo matemático.

Estruturas condicionais para comparação de valores.

Entrada de dados com Scanner.

🏪 Exercício 02 — Sistema de Controle de Estoque

Descrição:
Aplicação que gerencia as informações de um produto: nome, preço, quantidade e permite adicionar ou remover unidades do estoque.
O programa também calcula e exibe o valor total do estoque após cada atualização.

Conceitos abordados:

Classe produto com atributos e métodos de manipulação.

Cálculo do valor total em estoque (preço × quantidade).

Atualização dinâmica de valores.

Sobrescrita de toString() para formatação padronizada.

🎓 Exercício 03 — Avaliação de Notas do Aluno

Descrição:
Programa que lê o nome e as três notas de um aluno.
O sistema calcula a nota final e determina se o aluno está aprovado ou reprovado.
Caso reprovado, informa quantos pontos faltaram para atingir a média mínima (60.0).

Conceitos abordados:

Classe aluno com atributos nome, nota1, nota2, nota3.

Métodos notaFinal() e pontosFaltando().

Estruturas condicionais para avaliação lógica.

Formatação de saída com casas decimais.

💼 Exercício 04 — Cálculo Salarial com Desconto e Aumento

Descrição:
Aplicação que solicita o nome e o salário bruto de um funcionário, desconta o valor de um imposto e aplica um aumento percentual informado pelo usuário.
O resultado é exibido após cada operação, mostrando o salário atualizado.

Conceitos abordados:

Classe dados com métodos salarioDesconto() e salarioAumento().

Operações matemáticas com percentuais.

Exibição de valores monetários formatados.


Estrutura de entrada interativa com Scanner.
