🎯 Estruturas Repetitivas e Loops em Java

Neste repositório estou registrando meus exercícios sobre estruturas repetitivas e loops em Java.

🖥️ O que pratiquei

Durante esta lista de exercícios pratiquei:

💻 Entrada e validação de dados.

⚙️ Processamento com repetição controlada por condição.

🔁 Estrutura de repetição for e while.

🧠 Lógica de persistência de dados até que uma condição seja satisfeita.

🔹 Uso de condicionais dentro de laços.

🔹 Contagem e classificação de ocorrências em um loop.

🔹 Controle de fluxo com encerramento condicional (break).

🔹 Cálculo de médias, fatorial e divisores.

📚 Exercícios Resolvidos
Exercício 01 — Números Ímpares até X

Descrição:
Escrevi um programa que lê um número inteiro X e exibe todos os números ímpares de 1 até X, um por linha. Se X for ímpar, ele também é exibido.

Exercício 02 — Valores Dentro e Fora do Intervalo

Descrição:
Desenvolvi um programa que lê N valores inteiros e contabiliza quantos estão dentro do intervalo [10,20] e quantos estão fora.
O resultado é exibido como in para valores dentro do intervalo e out para valores fora.

Exercício 03 — Média Ponderada

Descrição:
Criei um programa que lê N casos de teste, cada um com 3 valores reais.
Calculei a média ponderada de cada conjunto, usando pesos 2, 3 e 5 para o primeiro, segundo e terceiro valor, respectivamente, exibindo o resultado com uma casa decimal.

Exercício 04 — Divisão com Verificação de Zero

Descrição:
Desenvolvi um programa que lê N pares de números e realiza a divisão do primeiro pelo segundo.
Quando o denominador é zero, exibo "divisao impossivel".

Exercício 05 — Fatorial

Descrição:
Escrevi um programa que lê um número N e calcula o seu fatorial.
Lembrei que, por definição, o fatorial de 0 é 1.

Exercício 06 — Divisores de um Número

Descrição:
Criei um programa que lê um número inteiro N e calcula todos os seus divisores, exibindo cada divisor em uma linha.

Exercício 07 — Número, Quadrado e Cubo

Descrição:

Desenvolvi um programa que lê um número N e exibe, para cada número de 1 até N, o valor, seu quadrado e seu cubo, um conjunto por linha.
